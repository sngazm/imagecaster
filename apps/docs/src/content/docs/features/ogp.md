## 概要

公開サイトの URL を SNS やチャットに貼ったときに出る画像（OGP 画像）を、ビルド時に描きます。
左にアートワーク、右にエピソード名が入った 1200×630 の JPEG です。

| ページ | 画像 | 載るもの |
|--------|------|----------|
| エピソード | `/og/{id}.jpg` | 番号、タイトル、番組名、公開日、長さ |
| トップ・一覧・番組について | `/og.jpg` | 番組名、ひとこと、作者、サイトのドメイン |

Discord への告知のカードも、Discord がこの画像を読んで作ります。

## 見た目の決まり

- **アートワーク**: その回のアートワークがあればそれを、無ければ番組のものを使う。
  どちらも取れなければ、色だけの四角を置く
- **背景**: アートワークを大きくぼかして白を被せたもの。回ごとのアートワークがあれば、背景もその回の色になる
- **差し色**（番号の色）: アートワークでいちばん目立つ鮮やかな色。黄色は読める暗さにすると濁るので、
  ほかに色があればそちらを取る
- **番号**: タイトルが `#12 タイトル` の形なら、`#12` を上に小さく出し、残りをタイトルにする
- **番組名**: 番組のタイトルが `番組名 - ひとこと` の形なら、番組名とひとことに分ける
- **タイトルの折り返し**: 文節（[BudouX](https://github.com/google/budoux)）で切る。
  「／」や「 / 」の後ろ、英単語のあいだでも切れる。行の長さはそろえる
- **字の大きさ**: 入るいちばん大きな字。ただし大きい字で細切れの行が並ぶなら、小さくして行を減らす。
  いちばん小さくしても入らなければ「…」で切る

## しくみ

| ファイル | 役割 |
|----------|------|
| `apps/web/src/lib/og.ts` | 画像の URL と、載せる中身を決める |
| `apps/web/src/lib/og-image.ts` | 描く（[satori](https://github.com/vercel/satori) で SVG にし、sharp で JPEG にする） |
| `apps/web/src/pages/og.jpg.ts` | 番組全体の画像 |
| `apps/web/src/pages/og/[id].jpg.ts` | エピソードごとの画像 |

フォントは Noto Sans JP（`@fontsource/noto-sans-jp`）。外へ取りに行かないので、ビルドは R2 以外に依存しません。

### URL に `?v=` が付く理由

SNS は OGP 画像を URL ごとに覚えています。タイトルやアートワークを直しても URL が同じだと古い画像が
出つづけるので、載せる中身から作った短い文字列を `?v=` に付けています。中身が変われば URL も変わります。

見た目そのものを変えたときは、`apps/web/src/lib/og-card.ts` の `OG_DESIGN_VERSION` を上げてください。
全部の画像の URL が変わります。

### ビルド時間

1 枚あたり 0.3 秒ほどかかります。エピソードが 300 回なら、ビルドが 1 分半ほど延びます。

## 手元で確かめる

```bash
pnpm dev:web
# http://localhost:4321/og.jpg
# http://localhost:4321/og/{id}.jpg
```
