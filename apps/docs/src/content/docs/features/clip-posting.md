管理画面で OK を出すときに投稿の日時・本文・投稿先を決めておくと、3 本の動画が描き終わった
あと、予定の時刻に投稿されます。Cron（5 分おき）が動かします。

| 投稿先 | 既定の形 | 出し方 |
|---|---|---|
| Bluesky | 正方形 | 自動 |
| Instagram（リール） | 縦 | 自動 |
| X | 横 | **手で出す** |
| YouTube Shorts | 縦 | **手で出す** |

## 自動で出すもの

投稿先ごとに結果を残します。1 つ失敗しても他は止まりません。失敗した先だけ次の回でやり直し、
5 回失敗したら諦めます。諦めたものは、管理画面の「もう一度試す」で再開できます。

動画を上げてから向こうの処理が済むまで待つので、予定の時刻から実際に出るまで 5〜10 分
掛かることがあります。

### Bluesky

エピソードの告知と同じ `BLUESKY_IDENTIFIER` / `BLUESKY_PASSWORD`（アプリパスワード）を使います。
アカウントのメール確認が済んでいる必要があります。本文は 300 字まで。リンクは自動でリンクになります。
動画とリンクカードは同時に付けられないので、リンクは本文に書きます。

### Instagram

1. Instagram のアカウントを**プロアカウント**（ビジネスかクリエイター）にする
2. [Meta for Developers](https://developers.facebook.com/) で **Business タイプ**のアプリを作り、
   「Instagram」製品を足す（Instagram Login の系統）
3. アプリのダッシュボードの Instagram API 設定で、自分のアカウントを足して **Generate token** を押す。
   出てくるのは最初から長期（60 日）のトークン
4. `wrangler secret put INSTAGRAM_ACCESS_TOKEN`

自分のアカウントにだけ出すので、アプリ審査もビジネス認証も要りません。

**トークンは 60 日で切れます。** 切れたら発行し直すしかありません。更新し続けるには、更新した
トークンの置き場として KV を足します（Worker は自分の secret を書き換えられず、R2 は公開されて
いるので鍵を置けません）。

```bash
wrangler kv namespace create CLIP_SECRETS
# 出てきた id を wrangler.toml に足す
# [[kv_namespaces]]
# binding = "CLIP_SECRETS"
# id = "…"
```

これがあれば、投稿のついでに週に 1 度トークンを更新します。無ければ更新せず、secret のトークンを
切れるまで使います。

:::caution
アプリが開発モードのままでも自分のアカウントには投稿できますが、その投稿がほかの人から
見えるかどうかは、公式の文書に書かれていません。**最初の 1 本を出したら、ログアウトした
ブラウザから見えるか確かめてください。**
:::

## 手で出すもの

描き終わると、管理画面の切り抜きの画面に、本文（コピーできます）と、その投稿先の形の動画を開く
リンクが並びます。出したら「出した」を押します。出した先の URL を添えておけます。全部の投稿先が
済むと「投稿済み」になります。

- **X**: API を使わない自動操作（ブラウザの操作を含む）は、X の自動化ルールが名指しで禁じていて、
  永久凍結の可能性が明記されています。x.com の予約投稿を人が使うぶんには問題ありません。
  動画は 140 秒 / 512MB まで（Premium でない場合）
- **YouTube**: 2020-07-28 より後に作った API プロジェクトは、Google の審査（compliance audit）を通るまで、
  API から上げた動画が非公開に固定されます。審査が通ったら自動に切り替えられます

調べた事実と出典は `docs/clip-viewer-spec.md` の「投稿」にあります。
